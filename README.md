# Юлия Павлова

Персональный сайт независимого финансового советника и преподавателя.

Направления работы: корпоративные тренинги, финансовая диагностика и советническая работа, финансовое моделирование и ИИ в финансах.

[Открыть сайт](https://juliaalexpavlova-eng.github.io/finance-practice/)

В разделе ИИ описаны завершённые проекты и приведены обезличенные примеры структуры моделей и управленческих панелей. Финансовые значения на иллюстрациях удалены.

Форма помогает подготовить текст запроса в браузере; посетитель отправляет его самостоятельно по указанным контактам.

Сайт состоит из HTML, CSS и JavaScript и размещается на GitHub Pages. Лицензии используемых шрифтов находятся в папке assets.
